Не запускать на production. Не создавать заказы в prod.

Перед тестом: `seed_synthetic.sql` на staging, вход `staging-manager@example.test`.
Телефон в накладных только синтетический: `77001112233`.

## A. Обычная накладная

```
Айгүл
2 Чай
1 Драже
Kaspi
```

Ожидание: продавец Айгүл, STAGING City, цены 500 и 300, сумма 1300, подтверждение активно. После кнопки: «Заказ N… успешно создан», чай 18, драже 19.

Не использовать голое «порошок» — в каталоге два порошка.

## B. Повтор после timeout

Slow 3G → «Подтвердить заказ». 202 или автоповтор 2 с. Один номер, одно списание.

После успеха: `UPDATE products SET price_retail = 999 WHERE name = 'Чай';` и снова «Подтвердить» на той же карточке → тот же номер, не 409.

Вернуть цену 500.

## C. Две вкладки

Один черновик, подтвердить в двух вкладках почти вместе → один заказ, один `idempotency_key`.

Ожидание: заказ из серверного черновика, не из тела.
